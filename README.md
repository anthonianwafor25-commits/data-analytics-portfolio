# BG Group Fashion Dashboard

## Project Overview
This project involved using Microsoft Power BI to explore and visualise data relating to the fashion business.

## Tool Used
- Microsoft Power BI

## Project Purpose
To transform business data into interactive visualisations that make information easier to understand and support data-driven decision-making.

## Skills Demonstrated
- Data visualisation
- Dashboard development
- Business data analysis
- Communicating insights through visual reports
